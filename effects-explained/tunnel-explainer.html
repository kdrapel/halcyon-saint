1. Work backwards from the screen

At 0x2CB81–0x2CCEC, the original loops over 41 columns and 26 rows. For each grid point it transforms a stored three-component vector using the current matrix and path-derived origin, then calls the selected mapping routine.

This is a screen-to-texture calculation. There are intersection calculations at the grid points; the renderer does not need a finely tessellated tube or an intersection calculation for every pixel.

The moving viewpoint comes from the original path evaluation: 0x1F324 evaluates cubic polynomials, and 0x2C9E8 copies their results into the frame’s transform inputs. Changing path time here advances the original timer and drawing sequence, including those path calculations.

2. Map a plane

The routine at 0x2A0F5 starts with an intersection against z = −400. Calling the origin O and the transformed point P:

D = P − O
t = (−400 − Oz) / Dz

The code also perturbs the intersection parameter using sine/cosine terms. It derives the two texture coordinates from the resulting x/y position and calculates a shading value. This is why “a flat checkerboard floor” was an incomplete account of the original effect.

3. Map a cylinder

The routine at 0x29D9A instead forms a quadratic using the x/y components:

A = Dx² + Dy²
B = 2(Ox·Dx + Oy·Dy)
C = Ox² + Oy² − R²
A·t² + B·t + C = 0

It selects a root using the square root of the discriminant, applies a sine-based perturbation, then uses an angle from the hit’s x/y coordinates for one texture coordinate and its z position for the other. A distance-related value supplies shading. The exact calculations, signs, rounding and lookup behavior run in the original translated routine here.

4. Blend the mappings

During a transition, both mapping routines run for the same grid point. At 0x2CC42, each output component is combined as:

result = cylinderResult · blend
       + planeResult · (1 − blend)

The experiment fixes the primary routine to the plane and the secondary to the cylinder, then writes your blend into the original float32 cell at 0x2B7E8. It enables the original transition branch and holds transition velocity at zero, suppressing its additional matrix translation while you change the blend. The path state comes from the selected time. The texture palette stays fixed, and the look target changes through its control. At blend 0 or 1 only the selected mapping runs, avoiding invalid values from an unused intersection.

In the original choreography the timer evolves the weight and its velocity, then swaps the mapping pointers when the transition finishes. The natural weight can briefly exceed 1; the manual control is limited to 0–1 so you can inspect the two endpoints.

5. Fill the gaps

The 41×26 samples bound 40×25 blocks of 8×8 pixels: the full 320×200 picture. The rasterizer interpolates the fixed-point U, V and shading values inside each block, samples the original indexed texture, and uses the original shading lookup. This experiment stops at the end of this background pass, before any object, sprite or logo drawing.
